# 글 운영체제 (Geul OS)

한글 프로그래밍 언어 **글(Geul)** 로 작성되는, 글 언어 개발 환경 그 자체가 되는 연구용 운영체제.

## 프로젝트 정체성

- **언어**: 글(Geul). 컴파일러는 [`C:\workspace\geul`](file:///C:/workspace/geul) 별도 프로젝트
- **목표**: 글 OS 안에서 글 코드를 작성·빌드·실행하고, 결국 글 컴파일러 자체를 글 OS 위에서 빌드
- **성격**: 연구용. 상용성·POSIX 호환·멀티 사용자 같은 누적된 부담을 처음부터 안 진다
- **모델 OS**: TempleOS(자체 언어+자체 OS), Singularity(소프트웨어 격리), seL4(능력 보안), KeyKOS(영속 메모리)에서 영감

## 핵심 차별점

1. **컴파일러가 격리를 보장** — MMU 페이지 테이블이 아니라 글 컴파일러의 타입 안전성으로 프로세스 격리
2. **능력 기반 보안** — 사용자 ID 같은 ambient authority 폐기, 권한 = 토큰
3. **단일 주소공간** — 64비트 주소공간 하나에 모든 실행체 공존, 컨텍스트 스위치 사실상 무료
4. **영속 메모리 모델** — 종료/재부팅이 사용자에게 안 보임. 항상 일시정지/재개
5. **한국어 통일성** — UTF-8 단일 인코딩, 셸 = 글 언어, 시스템 콜 = 글 함수 호출
