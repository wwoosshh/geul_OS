# 용어집

글 OS의 한국어 OS 용어. 영어 OS 용어를 한국어로 그대로 들고 오지 않고, **글 언어 어휘와 어울리는 신조어**를 채택한다. 이 문서는 의도적 명명 규약의 기록.

원칙:
- 합성어는 한국어 의미가 통할 것
- 글 렉서의 조사/어미와 충돌 안 할 것 (`~와`, `~이`, `~면`, `~는`, `~로`, `~서` 등 끝나는 식별자 회피)
- 약자보다 풀어쓰기 우선
- 같은 개념에 두 이름 안 둠

---

## 1. 커널/실행 모델

| 영어 | 글 OS 용어 | 비고 |
|------|-----------|------|
| Kernel | 핵심 또는 프레임핵심 | "커널"도 허용. 정착 후 결정 |
| Framekernel | 프레임핵심 | Theseus 용어. 핵심 + SIP 조합 의미 |
| Process | 실행체 | "프로세스" 직역 아님. SIP를 가리킬 때 사용 |
| SIP (Software Isolated Process) | 격리실행체 | 결정 A에서 정의됨 |
| Thread | 줄기 | "쓰레드" 음역 회피 |
| Context Switch | 문맥전환 | 표준 직역 |
| Scheduler | 일정관리자 | "스케줄러" 회피 |
| Preemption | 선점 | 표준 |
| Yield | 양보 | 글의 SOV와 어울림: `현재줄기가 양보` |

## 11. 명명 규약 (메타)

### 11-1. 합성어 분리 위험 검사 ~~(v0.8 이전)~~ → 해소됨

**글 v0.8.0 (2026-05-16)에서 R-02 완전 해결.** 변수 선언 시 합성어 식별자가 1바이트 조사 글자(이/가/와/과/로/의/에)로 끝나도 안전하게 통째 등록됨. 매개변수 컨텍스트만 별도로 분리.

→ 자유롭게 한국어 합성어 식별자 사용 가능: `블록와이`, `타이머인터럽트`, `페이지테이블엔트리`, `격리실행체`, `끼어들기처리기` 등.

매개변수 syntax `[정수 X로 함수]`는 그대로 (조사가 *역할*을 표현하므로 분리 정상).

### 11-2. 약자 정책

- 영어 약자(IDT, GDT, MMIO, DMA, IPC 등): 한국어 풀어쓰기를 1차로, 약자는 글로벌 합의가 강할 때만 보조 허용
- 한국어 합성어의 약자는 만들지 않음 (가독성 손실)

### 11-3. 동사형 함수 이름

글의 SOV 어순을 활용:
- `[페이지를 매핑]`, `[메시지를 SIP에 보내기]`, `[능력을 부여]`

### 11-4. 자료구조 이름

명사 합성어:
- `페이지표항목`, `격리실행체기술자`, `메시지헤더`, `능력토큰`
